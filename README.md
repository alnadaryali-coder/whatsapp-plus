# 📸 واتساب بلس — إرسال رسائل وصور لأرقام متعددة

تطبيق ويب (صفحة واحدة) بالعربية، يفتح محادثة واتساب جاهزة لكل رقم من قائمتك، مع دعم مشاركة الصور فعلياً عبر نظام المشاركة في الجوال.

## ✨ المميزات

- 📤 فتح محادثة واتساب جاهزة بالنص لكل رقم (عبر `wa.me`)
- 🌍 إضافة رمز الدولة تلقائياً للأرقام المحلية (يدعم +967، +966، +971 وغيرها)
- 📱 رفع ملف أرقام (CSV/TXT) أو إدخالها يدوياً
- 📊 إحصائيات: عدد المستلمين، الوقت المتوقع، المرسل، الصور
- ⏱️ تأخير بين الرسائل (3-15 ثانية) + وضع انتظار يدوي/تلقائي
- 🖼️ مشاركة الصورة مع النص **فعلياً** عبر زر «إرسال الصورة مع النص» (نظام المشاركة `navigator.share`)
- 💾 حفظ تلقائي للبيانات في المتصفح (لا تفقد أرقامك عند إغلاق الصفحة)
- 🔄 تصفير كامل **يدوي فقط** (لا يمسح شيئاً تلقائياً بعد الإرسال)
- 🌙 دعم الوضع الليلي

## 🚀 طريقة الاستخدام

1. افتح الملف `index.html` في متصفح الجوال (يفضل عبر رابط https)
2. أضف الأرقام (ملف أو يدوياً) — مثال: `771234567`
3. اكتب الرسالة (والصورة اختيارية)
4. اضغط **🚀 بدء الإرسال**
5. لكل رقم: اضغط «📤 إرسال الصورة مع النص» واختر واتساب من قائمة المشاركة، أو افتح المحادثة عبر الرابط

## ⚠️ ملاحظات

- رابط `wa.me` يفتح المحادثة بالنص فقط — الصورة تُرفق عبر زر المشاركة أو يدوياً
- زر المشاركة يعمل على الجوال (Android/iPhone) عبر رابط https
- استخدم بحذر — التطبيق يفتح محادثة لكل رقم في قائمتك

## 🛠️ التشغيل محلياً

```bash
# أي خادم ملفات بسيط
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
